# Create content: doc or other asset

Read the shared rules first: the content-core skill. Follow its step 1 (brief, guided or your own prompt, and cancel), step 2 (sources of truth, including references and, when it exists, curated content), 2a (companions), 3 (plan), 4 (voice and the clean asset), 5 (build and accessibility), 6 (self-review), 7 (the asset and its separate metadata record), 7a (revise, edit and delete) and 9 (hygiene). This skill adds only what is specific to a document or any other asset that is not a blog post, one-pager, infographic, pitch deck or ad (a brief, a FAQ page, a press release draft, a datasheet, a poster).

## What is specific to a doc

- state its purpose in the first lines and keep to what the sources support.
- Format: the host's document type, or .docx or .md if a file is asked for by name. For a visual piece such as a poster, use the host's design type or Codesign and look at the render.
- If the request is really one of the five named asset types, say so and hand off to that skill.
- For long documents run SEO Writers' audit-tone-honesty, audit-paragraph-structure and audit-eeat (core step 6).

## Copy-ready brief

```
Create a document with the Marketing OS create-content-doc skill.

Project: [project name]
What it is: [e.g. a member FAQ, a datasheet, a press release draft]
Audience: [who reads it]
Goal: [what the reader should understand or do afterwards]
Call to action and link: [if any]
Length or format: [e.g. two pages, .docx]
Facts to include: [with a source and date for each]
Anything to avoid: [topics, partner names, claims]
Sources and references (optional): [links, uploaded files, pasted text]

Use the project's brand and positioning outputs and its website content.
Give me a one-screen plan first, then the document.
Return status, sources and anything to confirm as a separate metadata record, not in the document.
```

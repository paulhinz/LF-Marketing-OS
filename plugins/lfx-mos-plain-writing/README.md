# Plain writing

This plugin adds one skill, `plain-writing`, that makes Claude write and revise
prose in a plain style: simple everyday words, complete sentences, no dashes,
no jargon, no analogies, and no filler.

## What it does

Once installed, Claude applies the plain-writing rules automatically whenever
it drafts or revises prose for you, such as documents, reports, summaries,
emails, or proposals. You do not need to ask for it by name.

When Claude removes or rewrites text during a revision, it also produces a
small HTML file that shows the before and after, with a diff view explaining
why each change was made.

## Install

Open the `.plugin` file in Claude desktop (Cowork mode) and accept the
install prompt. The skill will then be available across your sessions.

# Deck Outline — Quarterly Marketing Plan (~10–14 slides)

Widescreen 16:9. Brand Kit styling when available; otherwise clean LF-neutral. Ranked-goal style follows the PyTorch 2026 plan pattern: one summary slide listing all goals, then one deep-dive slide per goal. Keep body text ≥ 18pt; one idea per slide. Sources and "(manual)" markers go in speaker notes, never on slides.

## Slide-by-slide

1. **Title** — "[Project] — Q[N] [Year] Marketing Plan". One-line theme if a Message Foundation exists (its elevator pitch or a derivative). Date + "Prepared with the LFX Marketing OS Quarterly Plan Agent" in small text.

2. **How to read this plan** — three parts: Review (what happened), Direction (where we're focusing), Goals (what we'll achieve and what it costs). State the operating rule: ED/PL set goals; the CFT defines campaigns from them.

3. **Review: last quarter's goals vs. outcomes** — table: goal · KPI target · actual · % to goal · budget vs. spend. Color status (green ≥90%, yellow 60–89%, red <60%). One "what we learned" line per goal. *(Initial plans: replace with "Baseline" slide — the Review Snapshot as the starting position.)*

4. **Project health & marketing snapshot** — the Phase 1 Review Snapshot, visualized: health trend, audience, events, education, membership. Flag market/community shifts from Phase 2 in a callout.

5. **Direction: business-outcome emphasis** — six outcomes with ⬆ increase / ➡ hold / ⬇ deemphasize and a one-line rationale each. Include the project-stage framing sentence.

6. **The Q[N] goals, ranked** — all goals on one slide: rank, name, one-line description, outcome tag, headline KPI, budget. Badges where useful (TOP PRIORITY, NEW, CARRIED FORWARD).

7–N. **One slide per goal** — fixed layout:
   - Header: rank + imperative goal name + business-outcome tag
   - KPI block: quarterly target with baseline ("from X today") and data source
   - Budget: $ allocation (and % of total)
   - Timeline: 3–5 milestone markers across the quarter
   - Risks: 2–3, each with a one-line mitigation
   - Footer line: what success unlocks (why this rank)

N+1. **Budget summary** — allocation by goal + discretionary reserve; total; pie or stacked bar. Note: discretionary spend reported at next QBR.

N+2. **Decisions & next steps** — decisions the plan needs from leadership (with dates), then the hand-off: "CFT defines campaigns supporting each goal" and the next quarterly review date.

Optional final slide: closing line in the project's voice (Message Foundation), PyTorch-style ("Sell out the rooms. Fill the courses. Tell one story.") — only if a Message Foundation exists; never invent voice.

## Speaker notes requirements

- Every metric: source (LFX query / document name / "(manual)" + who supplied it)
- Goal slides: the Phase 3 discussion rationale — why this target, alternatives considered
- Review slide: any user corrections from the "does this match reality?" step
